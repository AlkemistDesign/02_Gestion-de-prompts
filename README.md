# 02 Dashboard
Este es un ejemplo del segundo ejercicio de la práctica de la asignatura de Vibe Coding. Dashboard de Estudio y Gestión de Prompts Proyecto desarrollado para la **Tarea 2: Dashboard** dentro de la práctica **Desarrollo con Vibe Coding** (EASD / ESI Valladolid, Curso 2026/2027).

## 📌 Descripción del Proyecto
Este proyecto es una aplicación web de **Dashboard de Estudio** enfocada en el registro de sesiones, control de hábitos y motivación mediante el seguimiento de rachas de días consecutivos de estudio. Ha sido desarrollado aplicando metodologías de **Vibe Coding** y **Harness Engineering**, utilizando modelos de IA (Gemini / Antigravity / Cursor / OpenCode) guiados por reglas estrictas de contexto, guardarraíles y especificaciones de diseño.

## 📁 Estructura del Repositorio
La carpeta `02_Dashboard` incluye la siguiente estructura técnica y de documentación

02_Dashboard
